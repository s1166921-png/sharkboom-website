# 环球护航 · 第四版

独立路由 `/motion`。依据本任务最近一组概念图中实际展示的第 3 张，以及用户要求增加环游动效与科技感的反馈实现。

原 `/`、`/ocean`、`/editorial`、共享 Showcase、全局样式、原 logo 与原三张主视觉保持不变。

## 实现

- 地球为 Three.js 实时渲染的球体，使用原创艺术化世界纹理、网格与边缘光。
- 海面与微缩建筑为原创透明图层；鲨鱼、货轮为独立图片图层，按轨道位置排序前后关系并环游。它们不是可任意观察每个角度的立体模型。
- 支持鼠标视差、水平拖动、左右方向键、暂停、播放和重置。
- 五类险种自动轮换，手动选择后停止自动轮换；详情与咨询使用原生对话框。
- 手机端使用单独适配的海面图层、响应式素材与可横滑的险种导航。
- 场景离开视口或页面隐藏时停止动画更新；暂停后不反复绘制静止地球。
- 遵循系统减少动态效果的设置；不支持 WebGL 时保留静态玻璃地球及独立图层。
- 联系方式与投保渠道待配置，不接收表单、支付或投保资料。

原生 ImageGen 原图保存在 `public/motion/*.png`，网页使用压缩后的 WebP。完整生成提示词及视觉参考保存在本地 `outputs/concepts/`；原 logo 直接使用 `/logo.png`。

标题字体为自托管 Noto Serif SC 字符子集，许可见 `public/motion/FONT-LICENSE.txt`。正文使用系统中文字体；普通界面图标沿用 Lucide。

## 验证

`npx tsc --project tsconfig.motion.json --noEmit` 检查本版前端。`npm run build` 构建全部四条路由。根目录 `design-qa.md` 记录浏览器检查与截图比较。

全项目原始 TypeScript 配置还包含模板后端桩文件，裸跑 `tsc --noEmit` 会报告其既有 Cloudflare Worker 类型缺失；本次未修改后端桩文件。
