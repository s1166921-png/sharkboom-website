# 鲨鲨航海 · 实时立体版

最新 3D 版为默认首页 `/`，也可通过 `/motion-3d` 直接访问。前三个模板分别保留在 `/professional`、`/ocean`、`/editorial`，原版式、业务内容和素材保留；共享预览导航补齐五个方案。上一版 `/motion` 仍可访问。

实时主场景使用实际三维网格：连续蒙皮的卡通鲨鱼、货轮、地理大陆、港口建筑、海面与底座，统一使用透视镜头、环境光、阴影和深度测试。首屏直接嵌入由同一模型导出的完整画面，3D 第一帧绘制完成后接管；加载过程与 WebGL 不可用时也保留完整场景。大陆数据为 Natural Earth 公有领域数据。

- 鲨鱼：圆头、白色腹部、双侧表情、圆润背鳍与分叉尾鳍；6 节骨骼及平滑蒙皮。
- 动画：独立循环的身体摆尾和眨眼，航行起伏、海面法线和焦散、三维尾迹、航线信标。接近货轮时小鲨跃起避让。启动时直接进入完整镜头，取消强制入场等待。
- 操作：拖动改变水平和俯仰视角，方向键调整镜头，点击场景触发小鲨跃起；播放、暂停、重置；关于区域可单独旋转同款角色。
- 适配：手机保留纵向滚动，拖动可探索场景；限制像素比，离屏和后台停止渲染，暂停后按需绘制；遵循系统减少动态效果设置。
- 模型：`public/studio/shark-mascot.glb` 为可复用独立角色，含 `Shark_Organic_Swim` 与 `Shark_Gentle_Blink` 动画。角色和场景均无栅格图片贴片。

建模源文件：`assets/3d/build-world.mjs`。重建模型：`node assets/3d/build-world.mjs`。地理数据原始来源：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson 。

## 首屏加载优化

- 生产场景模型：7,128,448 字节 → 602,839 字节，下载量降低 91.5%；独立角色：1,147,156 → 85,159 字节，降低 92.6%。保留完整六骨骼和两段动画，不进行网格简化。
- HTML 中直接包含桌面与手机的完整首帧和模型预加载链接；引擎成为必要依赖提前下载，模型请求与初始化并行。首屏图像是内嵌 WebP，避免额外图片请求。
- 内容哈希命名的生产资源可长期缓存。解码器仅在浏览器中初始化。显式压缩载荷以 `.bin` 提供，避免 Vinext 将 `.gz` URL 视为内部编码变体而不直接提供。
- `npm run assets:optimize` 从原始模型重建生产资源；`assets/3d/encode-posters.py` 从 `outputs/loading-qa` 的实际 WebGL 首帧生成内嵌画面。修改模型、镜头或材质后应同步更新首帧。
- `SCENE_PREVIEW_URL` 指向生产预览后运行 `npm run test:scene`，会验证 SSR 初始画面、实际模型 HTTP 交付、压缩解码、骨骼、动画、模型边界和不支持解压流时的回退。

首次动态效果启动仍需要资源下载和 GPU 初始化；这里消除的是空白与加载遮罩，并缩短真实 3D 的准备时间，不承诺任意设备和网络均可零毫秒启动。
